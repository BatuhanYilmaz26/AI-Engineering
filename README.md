# AI Engineering

A collection of AI engineering projects exploring language models, agents, and graph-based workflows. Each project lives in its own top-level folder.

## Projects

| Project | Overview |
| --- | --- |
| [LangChain Multi-Agent](LangChain-Multi-Agent/) | A Streamlit research assistant with search and reader agents, report generation, and editorial review. |
| [LangGraph](LangGraph/) | Eight notebooks exploring sequential and single-node graphs, prompt chaining, parallel work, conditional routing, and iterative evaluation. |

## Repository structure

```text
AI-Engineering/
|-- LangChain-Multi-Agent/
|   |-- app.py                 # Streamlit interface
|   |-- src/                   # Agents, tools, and research pipeline
|   |-- tests/                 # Offline interface and pipeline tests
|   |-- requirements.txt
|   `-- README.md              # Project overview and structure
|-- LangGraph/
|   |-- *.ipynb               # Eight LangGraph workflow notebooks
|   `-- requirements.txt
`-- README.md                  # Repository overview
```
